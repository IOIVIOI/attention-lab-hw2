## 一、研究目的与总体设计

本项目把三个经典实验包装成同一套虚构情境，以减少被试在不同页面间切换造成的操作差异。三个任务分别为：

1. **组件巡检（Search）**：特征搜索与联合搜索，加入空间线索和三种搜索集大小。
2. **流向确认（Flanker）**：中央箭头判断，加入近距和远距两种干扰项距离。
3. **输出读数（Cleveland–McGill）**：条形图与饼图的比例估计，加入有/无参考刻度。

每名被试完成全部三个任务。任务顺序随机；同一任务内的练习试次和正式试次也随机。每项实验的正式条件均包含至少 10 个试次（实际为 15 个或更多），满足作业对条件平衡和重复测量的要求。

### 变量总览

| 实验 | 自变量 | 因变量 | 主要比较 |
|---|---|---|---|
| 搜索 | 搜索类型（特征/联合）× 空间线索（有/无）× 集大小（8/16/24） | 正确试次的反应时、搜索斜率、线索收益、命中/漏报/虚报 | 联合搜索是否比特征搜索更陡；线索是否主要降低联合搜索斜率 |
| Flanker | 一致性（一致/不一致）× 干扰项距离（近/远） | 正确试次反应时、冲突效应、正确率 | 近距冲突效应是否大于远距 |
| 图形判断 | 图形格式（条形/饼图）× 刻度（有/无） | 绝对估计误差（百分点）、反应时 | 条形图是否更准；刻度是否更降低饼图误差 |

## 二、三项实验与相关理论

### 1. 组件巡检：特征搜索、联合搜索与空间线索

#### 任务说明

屏幕会出现由橙色和蓝色图形组成的模块阵列。故障模块是**橙色方块**，正常模块是**蓝色方块**或**橙色圆形**。被试需要判断阵列中是否存在橙色方块：

- 按 `J`：存在故障；
- 按 `F`：不存在故障。

在阵列出现前，扫描系统有时会高亮一个象限。高亮是有效空间线索：如果目标存在，目标一定在高亮象限内；但高亮象限也可能没有目标。提示在目标出现之前呈现，并在阵列出现前消失。

- 练习：10 次，有正误反馈。
- 正式：160 次。
- 集大小：8、16、24 个元素。
- 搜索超时：4000 ms。

#### 正式试次结构

目标存在的试次为：

`2 种搜索类型 × 2 种线索条件 × 3 种集大小 × 12 次 = 144 次`

无目标试次为：

`2 种搜索类型 × 2 种线索条件 × 4 次 = 16 次`

因此正式试次共 160 次。无目标试次的集大小从 8、16、24 中随机抽取，所以无目标条件不是按集大小做完全平衡。

#### 理论：特征整合理论（Feature Integration Theory, FIT）

Treisman 与 Gelade（1980）提出，视觉物体由颜色、形状、朝向等**特征**组成。某些搜索只需要检测一个显著特征，称为**特征搜索**。例如目标与其他项目的颜色明显不同，颜色本身就能把目标从背景中区分出来，通常表现为近似平行的搜索，集大小增加时反应时增长很小，因此斜率接近平。

**联合搜索**要求把两个或多个特征绑定为同一个物体。例如本实验的目标是「橙色」且「方块」；橙色圆形具有颜色特征，蓝色方块具有形状特征，只有两者的组合才是目标。FIT 认为，当目标不能靠单一特征区分时，需要把注意逐个指向候选项目并完成**特征绑定**，因此集大小增加时反应时增长更明显，搜索斜率更陡。

需要区分两个概念：

- **平行搜索**：多个项目可以同时处理，效率较高，集大小斜率较小。
- **序列搜索**：注意资源需要依次分配给候选项目，效率较低，集大小斜率较大。

FIT 是一个经典框架。后续研究指出，联合搜索并不总是严格序列的；当被试能利用分组、颜色引导或统计规律时，搜索也可能变得高效。因此本项目的重点是检验**相对斜率**，而不是断言所有联合搜索都必然为完全序列加工。

#### 改进条件：有效空间线索

空间线索来自 Posner（1980）的注意定向研究。线索在目标出现前把注意引向一个空间区域，可减少需要检查的区域，并提高该区域项目的视觉加工优先级。

本实验把线索设为完全有效的象限线索。理论上：

- 特征搜索本来就较容易，线索能够带来的额外收益有限；
- 联合搜索需要把注意分配给候选项目，缩小候选区域后，减少的注意分配和绑定负担更大；
- 因而线索应主要降低联合搜索的斜率，并产生更大的线索收益。

**线索收益**定义为：

`线索收益 = 无线索条件的中位反应时 − 有线索条件的中位反应时`

数值越大，表示线索带来的反应时优势越大。这里比较的是正确、未超时、页面保持可见的试次。

#### 研究问题与操作定义

- **搜索斜率**：以集大小为横轴、各集大小中位反应时为纵轴，计算每增加一个项目所增加的反应时（ms/item）。斜率用最小二乘直线拟合得到。
- **特征搜索斜率**：只使用特征搜索的正确目标存在试次。
- **联合搜索斜率**：只使用联合搜索的正确目标存在试次。
- **空间线索效应**：同一搜索类型下，无线索中位反应时减去有线索中位反应时。
- **漏报率**：目标存在但被试按 `F` 的比例。
- **虚报率**：目标不存在但被试按 `J` 的比例。

### 2. 流向确认：Flanker 冲突与干扰项距离

#### 任务说明

屏幕中央显示一个方向箭头，左右两侧显示与任务无关的箭头。被试只判断中央箭头方向：

- 按 `←`：中央箭头向左；
- 按 `→`：中央箭头向右。

两侧箭头与中央箭头的关系有两种：

- **一致（congruent）**：两侧箭头与中央箭头同向；
- **不一致（incongruent）**：两侧箭头与中央箭头反向。

两侧箭头与中央箭头的距离也有两种：

- **近距（near）**：两侧干扰项靠近中央目标；
- **远距（far）**：两侧干扰项与中央目标之间留有更大的水平间隔。

- 练习：10 次，有正误反馈。
- 正式：60 次。
- 四种条件各 15 次。
- 反应超时：2000 ms。

#### 理论：Flanker 效应与反应冲突

Eriksen 与 Eriksen（1974）的 Flanker 范式表明，当无关刺激与目标共享反应维度时，无关刺激会激活对应的反应。若两侧箭头与目标相反，两侧刺激激活错误反应，中央目标激活正确反应，两个反应表征发生竞争，导致不一致试次比一致试次更慢、更容易出错。这种差异称为 **Flanker 冲突效应**：

`冲突效应 = 不一致条件中位反应时 − 一致条件中位反应时`

本实验的关键改进是操纵干扰项与目标的空间距离。**空间选择性注意**可以抑制与目标位置相距较远、任务无关的刺激；距离越近，干扰项越难被排除，错误反应的激活越强，因此近距冲突效应应在理论上大于远距冲突效应。远距条件下，干扰项可能落在注意焦点之外，冲突效应可能接近消失。

这里需要区分：

- **冲突效应**：刺激之间的反应竞争造成的反应时差异；
- **空间距离**：干扰项与目标之间的物理间隔；
- **空间选择性注意**：把有限加工资源集中在目标位置、降低无关位置影响的能力。

### 3. 输出读数：Cleveland–McGill 图形比例判断与刻度

#### 任务说明

系统用条形图或饼图显示一个比例，高亮部分表示反应堆输出或冷却剂储备。被试拖动滑块估计高亮部分占整体的百分比，然后按 `Enter` 或点击「确认」。

- 图形格式：条形图或饼图。
- 参考刻度：有或没有 25%、50%、75% 刻度标记。
- 练习：6 次，会显示真实值和误差。
- 正式：60 次。
- 四种条件各 15 次。
- 真实值范围为 28% 到 72%，以约 4 个百分点的步长变化，并包含若干中间值。
- 估计超时：20000 ms。

#### 理论：图形解码与比例判断

Cleveland 与 McGill（1984）研究人们如何从图形中读取数量关系，提出不同视觉编码的精度并不相同。一般而言，人对**位置**和**长度**的判断较敏感，对**角度**和**面积**的判断较弱。条形图主要依赖长度/位置编码，饼图主要依赖角度和扇形面积编码，因此条形图通常应产生更小的比例估计误差。

Hollands 与 Dyre（2000）进一步讨论了比例判断中的系统性偏差以及参考信息的作用。**参考刻度**提供 25%、50%、75% 等锚点，让被试可以把待判断的比例与已知分段对齐，减少纯凭角度或长度做整体估计的困难。饼图的扇形边界是曲线，且缺少直线刻度时更难定位比例，因此刻度对饼图的帮助应大于对条形图的帮助。

本实验的因变量为**绝对误差**：

`绝对误差 = |被试估计百分比 − 真实百分比|`

绝对误差以百分点为单位，不区分高估和低估。实验没有把「估计偏大」当作正确或错误，而是衡量估计的准确程度。除误差外，页面还记录反应时。

图形 × 刻度的交互预测意味着不能只比较「条形 vs 饼图」或「有刻度 vs 无刻度」的主效应，而要比较四种组合：

- 条形图 + 无刻度；
- 条形图 + 有刻度；
- 饼图 + 无刻度；
- 饼图 + 有刻度。

## 三、收数前的预测（预注册）

> **重要说明：以下三条预测在正式收集他人数据之前写入 README，并提交到 Git。**  
> 预注册 commit：`d6bb2e0`  
> 记录时间：2026-11-11  
> 预测只描述方向，不预设具体数值；结果部分不得为了符合预测而改写、筛选或伪造数据。

### 预测 1：搜索类型与空间线索

- 特征搜索的集大小斜率应接近平；
- 联合搜索的斜率应明显更陡；
- 空间线索应主要降低联合搜索的斜率；
- 联合搜索的线索收益（无线索减有线索）理论上应大于特征搜索的线索收益。

**理论依据**：FIT 认为联合搜索需要额外的注意与特征绑定；有效空间线索缩小候选区域，因此对联合搜索的帮助应更大。特征搜索可由颜色等单一特征快速区分，线索的增量收益应较小。

### 预测 2：Flanker 冲突效应的距离差异

- 近距不一致条件的冲突效应应大于远距不一致条件；
- 远距条件的冲突效应可能很小，甚至接近消失。

**理论依据**：空间选择性注意对近邻干扰项的抑制更难；远距干扰项更容易被排除，错误反应激活较弱。

### 预测 3：图形格式、刻度与交互

- 条形图的绝对估计误差应小于饼图；
- 有刻度条件应降低误差，尤其是饼图的误差；
- 刻度对饼图的改善应大于对条形图的改善，即出现 **图形格式 × 刻度** 的交互。

**理论依据**：条形图的长度/位置编码比饼图的角度/面积编码更精确；刻度提供明确的参考锚点，能更大程度补偿饼图的角度估计困难。

## 四、方法

### 4.1 被试与伦理

- 被试为自愿参与的成年人，通过匿名网页完成实验。
- 页面在开始前显示知情同意，必须勾选同意后才能继续。
- 不收集姓名、学号、手机号或精确位置。
- 参与者编号由浏览器随机生成，仅用于把三项实验的记录归到同一名被试。
- 数据仅上传到课程「注意实验室」服务器，用于本课程教学分析。
- 被试可以关闭页面退出；未完成提交的数据不会被记录。
- 正式收数目标：至少 5 名他人完成全部三项实验。

### 4.2 设备、指导语与练习

- 建议在电脑上使用键盘完成，保持页面在前台。
- 开始前需关闭中文输入法，以免 `J`、`F` 和方向键输入被拦截。
- 每个任务先呈现任务简报和练习，再进入正式试次。
- 练习提供正误或真实值反馈；正式试次没有逐试次对错反馈。
- 三个任务的顺序随机；每项任务内的试次顺序随机。

### 4.3 计时与异常记录

- 反应时使用 `performance.now()` 计算，从刺激呈现到有效键盘/滑块确认。
- 页面隐藏、切换标签页或失焦会被记录为 `invalid = 1`。
- 超时记录为 `timeout = 1`，不计为正确试次。
- 搜索、Flanker 和图形判断的超时分别为 4000 ms、2000 ms 和 20000 ms。
- 每项实验在正式试次结束后单独上传；报告页可以重试失败的上传。

### 4.4 分析规则

本 README 在收数前固定以下描述性分析规则：

1. **搜索反应时**：仅使用目标存在、回答正确、未超时、未标记失效且有反应时的试次。
2. **搜索斜率**：先求每个集大小的中位反应时，再用集大小对中位反应时做最小二乘线性拟合，单位为 ms/item。
3. **搜索线索收益**：同一搜索类型下，无线索中位反应时减去有线索中位反应时，单位为 ms。
4. **Flanker 冲突效应**：同一距离下，不一致条件中位反应时减去一致条件中位反应时；仅使用正确、未超时、未失效的试次。
5. **图形误差**：使用非超时、未失效且有估计值的试次，计算绝对误差 `|estimate − true value|`，单位为百分点。
6. **个体层面汇总**：先在每名被试内部计算指标，再计算组均值、标准差和样本量，避免把所有试次混在一起造成伪重复。
7. **不额外删除慢反应**：除上述正确性、超时和页面失效规则外，不根据结果临时设置反应时上限；若后续需要改变规则，必须在 README 中说明原因并同时报告敏感性分析。

网页现有的结果面板采用「每位参与者最后一条记录」去重，并展示个体指标汇总。正式论文中的推断统计可在数据齐全后补充配对检验、混合模型或 bootstrap 置信区间；这些推断方法不改变上述原始指标定义。

### 4.5 试次与条件平衡

| 实验 | 条件数 | 每条件正式试次 | 正式总数 |
|---|---:|---:|---:|
| 搜索 | 存在/缺失 × 类型 × 线索 × 集大小 | 目标存在单元各 12；无目标单元各 4 | 160 |
| Flanker | 一致性 × 距离 | 15 | 60 |
| 图形判断 | 格式 × 刻度 | 15 | 60 |

条件顺序随机。图形判断的每个条件使用同一组 15 个比例值，但各条件内部随机排序，以免固定顺序造成系统偏差。

### 5.3 讨论提纲（不得提前写成结论）

正式数据到手后，按以下顺序讨论：

1. **搜索**：特征搜索斜率是否接近平？联合搜索是否更陡？如果线索主要降低联合搜索斜率，支持注意资源与特征绑定的解释；如果线索对两类搜索都产生相近收益，则支持空间范围或一般警觉性解释。
2. **Flanker**：近距冲突是否大于远距？若远距冲突仍显著，说明空间分离没有完全消除反应竞争；若远距效应消失，支持注意焦点对干扰项的过滤作用。
3. **图形判断**：条形图误差是否小于饼图？刻度是否只改善饼图？若出现交互，应报告四种条件的简单效应，而不是只解释主效应。
4. **局限**：在线实验无法严格控制设备亮度、观看距离和输入法；反应时可能受浏览器、刷新率和操作熟练度影响。样本量较小时，组均值不稳定，需要同时报告个体数据或置信区间。
5. **与原文比较**：只比较方向和相对大小，不把本实验的具体数值当作对原论文数值的精确复现。

## 八、数据上传与字段

### 8.1 上传接口

```http
POST https://attention-lab-production.up.railway.app/api/hw2/submit
Content-Type: application/json
```

主要请求字段：

```json
{
  "project": "NVTQ9T",
  "experiment": "search",
  "participant": "Q-XXXX",
  "condition": "",
  "trials": [],
  "meta": {}
}
```

正式实验名为 `search`、`flanker`、`cm`。测试模式会自动加上 `test_` 前缀。

### 8.2 试次字段

搜索试次：

```text
cond, type, cue, set, present, resp, correct, rt, timeout, invalid
```

Flanker 试次：

```text
cond, congruent, dist, dir, resp, correct, rt, timeout, invalid
```

图形判断试次：

```text
cond, format, ticks, val, est, err, rt, timeout, invalid
```

其中：

- `rt`：反应时，单位 ms；
- `timeout`：是否超时；
- `invalid`：页面是否在试次中隐藏或失效；
- `correct`：搜索/Flanker 的作答是否正确；
- `err`：图形估计的绝对误差；
- `meta`：匿名参与者编号、年龄段、色觉、设备、任务顺序、页面尺寸和浏览器信息等，不包含姓名或学号。

项目码 `NVTQ9T` 用于区分本作业项目。项目下载密钥不写入仓库，也不应公开提交到 Git。
